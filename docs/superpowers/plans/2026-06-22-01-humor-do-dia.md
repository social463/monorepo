# Humor do Dia — Implementation Plan (fase 1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adicionar ao Meu Perfil uma área onde a pessoa registra, uma vez por dia, seu humor numa escala de 5, salvando histórico diário privado (sem alterar o avatar).

**Architecture:** Segue o padrão do repo — contrato em `@legends/shared`, novo model Prisma `MoodEntry` (1 registro por usuário por dia, upsert), rotas finas `route → service → serialize` protegidas por `app.authenticate` operando só sobre `request.user.sub`, e um componente React isolado (`MoodOfDay`) renderizado no `ProfilePage` apenas no próprio perfil.

**Tech Stack:** TypeScript ESM, Fastify 4 + Prisma 5 + PostgreSQL (apps/api), Vite + React 18 + React Query + Tailwind (apps/web), Zod, Vitest (+ Postgres real na API, jsdom/Testing Library no web).

## Global Constraints

- TypeScript **strict**, ESM puro. `pnpm build`/Vitest **não** fazem typecheck — rode `tsc --noEmit` por workspace ao mudar DTOs/contrato.
- Mensagens ao usuário em **português** (pt-BR).
- Camadas finas e separadas: sem regra de negócio nas rotas; lógica no service; DTO em `serialize.ts`; contrato em `@legends/shared` (fonte única — altere o tipo lá primeiro).
- Testes da API batem em **Postgres real** — suba com `pnpm db:up` antes de `pnpm test`.
- **Nunca** editar uma migration já aplicada — gerar nova.
- "Dia" = data civil no fuso **America/Sao_Paulo**.
- Privacidade: o humor **não** altera o avatar e **não** é exposto a terceiros nesta fase. Sem contador de ofensiva/streak nesta fase.
- Front fala com a API por caminhos relativos via `apiFetch` (proxy nginx) — nunca cravar `localhost:3333`.

```ts
import type { MoodLevel } from '@legends/shared'
import { prisma } from '../lib/prisma'

/**
 * Dia civil em America/Sao_Paulo. Retorna o `ymd` (YYYY-MM-DD) para o DTO e um
 * `day` Date à meia-noite UTC cujo componente de data é exatamente esse dia civil
 * — independente do fuso do servidor —, usado como chave do registro diário.
 */
export function todayInSaoPaulo(): { ymd: string; day: Date } {
  const ymd = new Intl.DateTimeFormat('en-CA', {
    timeZone: 'America/Sao_Paulo',
    year: 'numeric',
    month: '2-digit',
    day: '2-digit',
  }).format(new Date())
  return { ymd, day: new Date(`${ymd}T00:00:00.000Z`) }
}

export async function getTodayMood(userId: string): Promise<MoodLevel | null> {
  const { day } = todayInSaoPaulo()
  const entry = await prisma.moodEntry.findUnique({
    where: { userId_day: { userId, day } },
  })
  return entry ? (entry.mood as MoodLevel) : null
}

export async function setTodayMood(userId: string, mood: MoodLevel): Promise<MoodLevel> {
  const { day } = todayInSaoPaulo()
  const entry = await prisma.moodEntry.upsert({
    where: { userId_day: { userId, day } },
    create: { userId, day, mood },
    update: { mood },
  })
  return entry.mood as MoodLevel
}
```

```ts
import type { FastifyInstance } from 'fastify'
import { z } from 'zod'
import { MOOD_LEVELS } from '@legends/shared'
import { getTodayMood, setTodayMood, todayInSaoPaulo } from '../services/mood-service'
import { toTodayMoodDTO } from '../lib/serialize'

const setMoodSchema = z.object({
  mood: z.enum(MOOD_LEVELS),
})

export async function moodRoutes(app: FastifyInstance) {
  app.get('/me/mood/today', { onRequest: [app.authenticate] }, async (request, reply) => {
    const { ymd } = todayInSaoPaulo()
    const mood = await getTodayMood(request.user.sub)
    return reply.send(toTodayMoodDTO(ymd, mood))
  })

  app.put('/me/mood/today', { onRequest: [app.authenticate] }, async (request, reply) => {
    const parsed = setMoodSchema.safeParse(request.body)
    if (!parsed.success) {
      return reply.code(400).send({ message: 'Dados inválidos', issues: parsed.error.issues })
    }
    const { ymd } = todayInSaoPaulo()
    const mood = await setTodayMood(request.user.sub, parsed.data.mood)
    return reply.send(toTodayMoodDTO(ymd, mood))
  })
}
```

```tsx
import { useState } from 'react'
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query'
import type { MoodLevel, TodayMoodDTO } from '@legends/shared'
import { MOOD_OPTIONS } from '@legends/shared'
import { apiFetch } from '../../lib/api'

export function MoodOfDay() {
  const queryClient = useQueryClient()
  const [editing, setEditing] = useState(false)

  const todayQuery = useQuery({
    queryKey: ['mood-today'],
    queryFn: () => apiFetch<TodayMoodDTO>('/me/mood/today'),
  })

  const setMood = useMutation({
    mutationFn: (mood: MoodLevel) =>
      apiFetch<TodayMoodDTO>('/me/mood/today', {
        method: 'PUT',
        body: JSON.stringify({ mood }),
      }),
    onSuccess: (data) => {
      queryClient.setQueryData(['mood-today'], data)
      setEditing(false)
    },
  })

  if (todayQuery.isLoading || !todayQuery.data) return null

  const current = todayQuery.data.mood
  const selected = current ? MOOD_OPTIONS.find((o) => o.value === current) : undefined
  const showPicker = !current || editing

  return (
    <div className="mb-lg rounded-xl border border-outline-variant/40 bg-surface-container p-lg">
      {showPicker ? (
        <>
          <h3 className="mb-md font-label text-label-md uppercase tracking-widest text-primary">
            Como você está se sentindo hoje?
          </h3>
          <div className="flex flex-wrap gap-sm">
            {MOOD_OPTIONS.map((option) => (
              <button
                key={option.value}
                type="button"
                aria-label={option.label}
                disabled={setMood.isPending}
                onClick={() => setMood.mutate(option.value)}
                className="flex flex-col items-center gap-1 rounded-lg border border-outline-variant/40 bg-surface-container-low px-md py-sm transition-colors hover:border-primary hover:bg-primary/5 disabled:opacity-50"
              >
                <span className="text-2xl" aria-hidden="true">{option.emoji}</span>
                <span className="font-label text-label-sm text-on-surface-variant">{option.label}</span>
              </button>
            ))}
          </div>
        </>
      ) : (
        <div className="flex items-center justify-between gap-md">
          <p className="flex items-center gap-sm font-body text-body-lg text-on-surface">
            <span className="text-2xl" aria-hidden="true">{selected?.emoji}</span>
            Hoje você está: <span className="font-medium">{selected?.label}</span>
          </p>
          <button
            type="button"
            onClick={() => setEditing(true)}
            className="font-label text-label-sm text-primary hover:underline"
          >
            alterar
          </button>
        </div>
      )}
    </div>
  )
}
```
