# Ex-Lendas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dar a quem sai do time um "Hall da Fama" (Ex-Lendas) preservando todo o histórico, com o perfil acessível e marcado, e-mail oculto, e acesso já bloqueado pelo `active`.

**Architecture:** Novo campo `User.leftAt DateTime?` marca ex-lenda (independente do boolean `active`, que já bloqueia login/votação). Backend ganha filtro `former` no showcase e aceita `leftAt` no PATCH admin; `toPublicUser` passa a ocultar o e-mail de ex-lenda. Frontend ganha uma aba "Ex-Lendas" na galeria, um selo no perfil e uma ação "Desligar" no admin.

**Tech Stack:** Fastify 4 + Prisma 5 + PostgreSQL (apps/api), Vite 5 + React 18 + React Query + Tailwind (apps/web), tipos compartilhados em @legends/shared, Vitest.

## Global Constraints

- ESM puro, TypeScript **strict**. Após mudar DTO/schema, rode `tsc --noEmit` no workspace afetado (o build/Vitest não faz typecheck do projeto).
- Mensagens ao usuário em **português**.
- Camadas finas: route valida com Zod (`safeParse`) → service → Prisma. Nada de regra de negócio na route.
- Contrato é fonte única: mude o tipo em `@legends/shared` **antes** de ajustar api/web.
- Testes da API batem em Postgres real: rode `pnpm db:up` antes de `pnpm test`. `pnpm db:migrate` gera migrations; **nunca** edite migration já aplicada.
- **Semântica-chave:** `active=false` bloqueia acesso/votação (já existe). `leftAt != null` = **ex-lenda** (entra no Hall da Fama). Os dois são independentes — não acople.

```ts
export function toPublicUser(user: User): PublicUser {
  return {
    id: user.id,
    name: user.name,
    // E-mail é ocultado para ex-lendas (quem já saiu do time).
    email: user.leftAt ? null : user.email,
    role: user.role,
    area: user.area,
    position: user.position,
    squad: user.squad,
    photoUrl: user.photoUrl,
    avatarStyle: user.avatarStyle as AvatarStyleKey | null,
    avatarSeed: user.avatarSeed,
    avatarOptions: (user.avatarOptions as AvatarOptions | null) ?? null,
    active: user.active,
    joinedAt: user.joinedAt.toISOString(),
    leftAt: user.leftAt ? user.leftAt.toISOString() : null,
  }
}

export function toAdminUser(user: User): AdminUserDTO {
  // Admin sempre enxerga o e-mail real, mesmo de ex-lenda.
  return { ...toPublicUser(user), email: user.email, teamsWebhookUrl: user.teamsWebhookUrl }
}
```
