# 1:1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a seção de 1:1 do Legends — agendamento com ritmo fixo que aparece no calendário, pauta a partir de catálogo da empresa, observações privadas por pessoa, ações compartilhadas que atravessam encontros e ponte para o PDI.

**Architecture:** Cinco models novos (`OneOnOneSeries`, `OneOnOneMeeting`, `OneOnOneTopic`, `OneOnOnePrivateNote`, `OneOnOneAction`) + o catálogo `OneOnOneTopicTemplate`. A série guarda o par com ids **normalizados** (ordenados), o que faz "ações abertas do par" ser uma consulta direta; as ocorrências são materializadas na criação (cada encontro precisa de id estável para ser alvo de FK de pauta/nota/ação). Rota fina → service → Prisma, com `scopedPrisma(companyId)` em toda consulta. No front, uma área própria em `/1-1` dentro do grupo Desenvolvimento e um quinto filtro derivado no calendário.

**Tech Stack:** Fastify 4, Prisma 5, PostgreSQL, Zod, React 18 + React Query, Tailwind, Vitest.

**Spec:** `docs/superpowers/specs/2026-08-05-um-a-um-design.md`

## Global Constraints

- TypeScript **strict**, ESM puro. Mensagens ao usuário **em português**.
- Contrato muda **primeiro** em `@legends/shared`, depois os dois lados.
- Toda consulta de API usa `scopedPrisma(viewer.companyId)` — nunca `prisma` direto num service novo.
- Models novos **não** levam `@default("company-emr")` no `companyId` (esse default é herança do retrofit multi-empresa); o valor vai explícito no `create`.
- Todo model novo entra em `TENANT_SCOPED_MODELS` (`apps/api/src/lib/tenant-scope.ts`) — sem isso não há isolamento.
- **Nunca editar migration já aplicada.** Gerar nova com `pnpm db:migrate`.
- Erro de domínio: classe com `status` HTTP; a rota faz `instanceof` e responde `err.status`.
- **Privacidade é do service**: nota privada de outra pessoa nunca entra em DTO nenhum; terceiro (inclusive ADMIN) recebe **404** em qualquer recurso de 1:1.
- Testes ao lado do código (`*.test.ts`). API precisa de Postgres: `pnpm db:up` antes.
- Durante a implementação rode só o arquivo de teste alterado; a suíte cheia só na verificação final.
- Teto de ocorrências materializadas por série: **52** (`MAX_ONE_ON_ONE_OCCURRENCES`).

```ts
// packages/shared/src/one-on-one.ts
/**
 * Contrato do 1:1 — o ritual de conversa entre duas pessoas.
 *
 * O par é guardado com os ids ORDENADOS (`normalizeOneOnOnePair`): é isso que
 * faz "as ações abertas deste par" ser uma consulta direta, e não um OR de duas
 * combinações espalhado por todo service.
 */

export const ONE_ON_ONE_RECURRENCES = ['NONE', 'WEEKLY', 'BIWEEKLY', 'MONTHLY'] as const
export type OneOnOneRecurrence = (typeof ONE_ON_ONE_RECURRENCES)[number]

export const ONE_ON_ONE_RECURRENCE_LABELS: Record<OneOnOneRecurrence, string> = {
  NONE: 'Não se repete',
  WEEKLY: 'Toda semana',
  BIWEEKLY: 'A cada duas semanas',
  MONTHLY: 'Todo mês',
}

export const ONE_ON_ONE_MEETING_STATUSES = ['SCHEDULED', 'DONE', 'CANCELED'] as const
export type OneOnOneMeetingStatus = (typeof ONE_ON_ONE_MEETING_STATUSES)[number]

/** `PROMOTED` = virou ação de PDI; sai dos pendentes sem ter sido concluída aqui. */
export const ONE_ON_ONE_ACTION_STATUSES = ['OPEN', 'DONE', 'PROMOTED'] as const
export type OneOnOneActionStatus = (typeof ONE_ON_ONE_ACTION_STATUSES)[number]

export const ONE_ON_ONE_TOPIC_ORIGINS = ['TEMPLATE', 'CUSTOM'] as const
export type OneOnOneTopicOrigin = (typeof ONE_ON_ONE_TOPIC_ORIGINS)[number]

/** Teto de ocorrências materializadas por série — série sem fim não gera até 2099. */
export const MAX_ONE_ON_ONE_OCCURRENCES = 52
export const ONE_ON_ONE_TOPIC_MAX_LENGTH = 200
export const ONE_ON_ONE_ACTION_DESCRIPTION_MAX_LENGTH = 400
export const ONE_ON_ONE_NOTE_MAX_LENGTH = 5000
export const ONE_ON_ONE_DURATIONS_MINUTES = [15, 30, 45, 60, 90] as const

export function normalizeOneOnOnePair(a: string, b: string): { userAId: string; userBId: string } {
  if (a === b) throw new Error('Um 1:1 precisa de duas pessoas diferentes.')
  return a < b ? { userAId: a, userBId: b } : { userAId: b, userBId: a }
}
```

```prisma
/// O par e o ritmo do 1:1. `userAId`/`userBId` são guardados ORDENADOS pelo id
/// (ver `normalizeOneOnOnePair` em @legends/shared): é o que torna "as ações
/// abertas deste par" uma consulta direta, e não um OR das duas combinações.
model OneOnOneSeries {
  id              String             @id @default(cuid())
  userAId         String
  userBId         String
  createdById     String
  recurrence      OneOnOneRecurrence @default(NONE)
  recurrenceUntil DateTime?
  durationMinutes Int                @default(30)
  endedAt         DateTime?
  companyId       String
  createdAt       DateTime           @default(now())
  updatedAt       DateTime           @updatedAt

  userA     User             @relation("OneOnOneUserA", fields: [userAId], references: [id], onDelete: Cascade)
  userB     User             @relation("OneOnOneUserB", fields: [userBId], references: [id], onDelete: Cascade)
  createdBy User             @relation("OneOnOneCreated", fields: [createdById], references: [id])
  company   Company          @relation(fields: [companyId], references: [id])
  meetings  OneOnOneMeeting[]
  actions   OneOnOneAction[]

  @@index([companyId, userAId, userBId])
  @@index([companyId, userBId])
}

/// Uma ocorrência. MATERIALIZADA (diferente de CalendarEvent, cuja recorrência é
/// expandida em consulta): cada encontro carrega pauta, nota e ações próprias e
/// precisa de id estável para ser alvo de FK.
model OneOnOneMeeting {
  id        String                @id @default(cuid())
  seriesId  String
  startsAt  DateTime
  endsAt    DateTime
  status    OneOnOneMeetingStatus @default(SCHEDULED)
  companyId String
  createdAt DateTime              @default(now())
  updatedAt DateTime              @updatedAt

  series OneOnOneSeries        @relation(fields: [seriesId], references: [id], onDelete: Cascade)
  company Company              @relation(fields: [companyId], references: [id])
  topics  OneOnOneTopic[]
  notes   OneOnOnePrivateNote[]
  actions OneOnOneAction[]      @relation("OneOnOneActionCreatedIn")

  @@index([seriesId, startsAt])
  @@index([companyId, startsAt])
}

/// Item de pauta. O texto vindo do catálogo é COPIADO, não referenciado por FK:
/// o catálogo muda, a pauta de um encontro passado é registro histórico.
model OneOnOneTopic {
  id          String              @id @default(cuid())
  meetingId   String
  text        String
  origin      OneOnOneTopicOrigin @default(CUSTOM)
  discussed   Boolean             @default(false)
  sortOrder   Int                 @default(0)
  createdById String
  companyId   String
  createdAt   DateTime            @default(now())

  meeting   OneOnOneMeeting @relation(fields: [meetingId], references: [id], onDelete: Cascade)
  createdBy User            @relation("OneOnOneTopicsCreated", fields: [createdById], references: [id])
  company   Company         @relation(fields: [companyId], references: [id])

  @@index([meetingId, sortOrder])
  @@index([companyId])
}

/// A observação privada. Uma por pessoa por encontro. NUNCA sai da API para o
/// outro participante — a consulta filtra por authorId, não a tela.
model OneOnOnePrivateNote {
  id        String   @id @default(cuid())
  meetingId String
  authorId  String
  body      String   @db.Text
  companyId String
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  meeting OneOnOneMeeting @relation(fields: [meetingId], references: [id], onDelete: Cascade)
  author  User            @relation("OneOnOneNotes", fields: [authorId], references: [id], onDelete: Cascade)
  company Company         @relation(fields: [companyId], references: [id])

  @@unique([meetingId, authorId])
  @@index([companyId])
}

/// O combinado. Preso à SÉRIE (logo, ao par): aparece em todo encontro do par
/// até fechar. `promotedPdiActionId` guarda a PdiAction que nasceu dele.
model OneOnOneAction {
  id                  String               @id @default(cuid())
  seriesId            String
  createdInMeetingId  String
  description         String
  ownerId             String
  dueDate             DateTime?
  status              OneOnOneActionStatus @default(OPEN)
  completedById       String?
  completedAt         DateTime?
  promotedPdiActionId String?              @unique
  companyId           String
  createdAt           DateTime             @default(now())
  updatedAt           DateTime             @updatedAt

  series           OneOnOneSeries  @relation(fields: [seriesId], references: [id], onDelete: Cascade)
  createdInMeeting OneOnOneMeeting @relation("OneOnOneActionCreatedIn", fields: [createdInMeetingId], references: [id], onDelete: Cascade)
  owner            User            @relation("OneOnOneActionsOwned", fields: [ownerId], references: [id], onDelete: Cascade)
  completedBy      User?           @relation("OneOnOneActionsCompleted", fields: [completedById], references: [id])
  promotedPdiAction PdiAction?     @relation("OneOnOnePromotedAction", fields: [promotedPdiActionId], references: [id], onDelete: SetNull)
  company          Company         @relation(fields: [companyId], references: [id])

  @@index([seriesId, status])
  @@index([companyId, ownerId, status])
```

```ts
import {
  MAX_ONE_ON_ONE_OCCURRENCES,
  normalizeOneOnOnePair,
  type CreateOneOnOneRequest,
  type OneOnOneMeetingDetailDTO,
  type OneOnOneMeetingSummaryDTO,
} from '@legends/shared'
import { scopedPrisma } from '../lib/tenant-scope'
import {
  toOneOnOneActionDTO,
  toOneOnOneMeetingSummary,
  toOneOnOneTopicDTO,
  type OneOnOneMeetingWithSeries,
} from '../lib/serialize-one-on-one'

export class OneOnOneError extends Error {
  status: number
  constructor(message: string, status = 400) {
    super(message)
    this.name = 'OneOnOneError'
    this.status = status
  }
}

export interface OneOnOneViewer {
  userId: string
  companyId: string
}

const SERIES_INCLUDE = { series: { include: { userA: true, userB: true } } } as const

const DAY_MS = 24 * 60 * 60 * 1000

/** Passo da recorrência em dias; `MONTHLY` é tratado à parte (mês civil). */
const STEP_DAYS: Record<string, number> = { WEEKLY: 7, BIWEEKLY: 14 }

/**
 * As datas de cada ocorrência. Série sem fim declarado gera o teto
 * (`MAX_ONE_ON_ONE_OCCURRENCES`) em vez de linhas até 2099; `recurrenceUntil` e
 * `recurrenceCount` são exclusivos entre si (a rota valida).
 */
export function occurrenceDates(input: {
  first: Date
  recurrence: string
  until: Date | null
  count: number | null
}): Date[] {
  if (input.recurrence === 'NONE') return [input.first]
  const limite = Math.min(input.count ?? MAX_ONE_ON_ONE_OCCURRENCES, MAX_ONE_ON_ONE_OCCURRENCES)
  const datas: Date[] = []
  for (let i = 0; i < limite; i += 1) {
    const data = new Date(input.first)
    if (input.recurrence === 'MONTHLY') data.setMonth(data.getMonth() + i)
    else data.setTime(data.getTime() + i * STEP_DAYS[input.recurrence] * DAY_MS)
    if (input.until && data > input.until) break
    datas.push(data)
  }
  return datas
}

/**
 * O encontro que o viewer pode ver: só quem está no par. Terceiro recebe 404 —
 * nem confirma a existência. ADMIN não é exceção: 1:1 é conversa privada.
 */
async function findParticipantMeeting(
  viewer: OneOnOneViewer,
  meetingId: string,
): Promise<OneOnOneMeetingWithSeries> {
  const meeting = await scopedPrisma(viewer.companyId).oneOnOneMeeting.findUnique({
    where: { id: meetingId },
    include: SERIES_INCLUDE,
  })
  if (!meeting) throw new OneOnOneError('1:1 não encontrado.', 404)
  const { userAId, userBId } = meeting.series
  if (viewer.userId !== userAId && viewer.userId !== userBId) {
    throw new OneOnOneError('1:1 não encontrado.', 404)
  }
  return meeting
}

export async function createSeries(
  viewer: OneOnOneViewer,
  input: CreateOneOnOneRequest,
): Promise<{ seriesId: string; meetings: OneOnOneMeetingSummaryDTO[] }> {
  const db = scopedPrisma(viewer.companyId)
  if (input.counterpartId === viewer.userId) {
    throw new OneOnOneError('Escolha outra pessoa para o 1:1.')
  }
  // `scopedPrisma` já recorta por empresa: pessoa de outro tenant simplesmente
  // não existe daqui, e a resposta é 404 — não 403.
  const outro = await db.user.findUnique({ where: { id: input.counterpartId } })
  if (!outro || !outro.active) throw new OneOnOneError('Pessoa não encontrada.', 404)

  const first = new Date(`${input.date}T${input.startTime}:00`)
  if (Number.isNaN(first.getTime())) throw new OneOnOneError('Data ou hora inválida.')

  const datas = occurrenceDates({
    first,
    recurrence: input.recurrence,
    until: input.recurrenceUntil ? new Date(`${input.recurrenceUntil}T23:59:59`) : null,
    count: input.recurrenceCount ?? null,
  })
  if (datas.length === 0) throw new OneOnOneError('A recorrência não gera nenhum encontro.')

  const { userAId, userBId } = normalizeOneOnOnePair(viewer.userId, input.counterpartId)
  const series = await db.oneOnOneSeries.create({
    data: {
      userAId,
      userBId,
      createdById: viewer.userId,
      recurrence: input.recurrence,
      recurrenceUntil: input.recurrenceUntil ? new Date(`${input.recurrenceUntil}T23:59:59`) : null,
      durationMinutes: input.durationMinutes,
      companyId: viewer.companyId,
      meetings: {
        create: datas.map((startsAt) => ({
          startsAt,
          endsAt: new Date(startsAt.getTime() + input.durationMinutes * 60_000),
          companyId: viewer.companyId,
        })),
      },
    },
    include: { userA: true, userB: true, meetings: { orderBy: { startsAt: 'asc' } } },
  })

  const meetings = series.meetings.map((meeting) =>
    toOneOnOneMeetingSummary({ ...meeting, series }, viewer.userId, 0),
  )
  return { seriesId: series.id, meetings }
}

export async function listMeetings(
  viewer: OneOnOneViewer,
  from: string,
  to: string,
): Promise<OneOnOneMeetingSummaryDTO[]> {
  const db = scopedPrisma(viewer.companyId)
  const meetings = await db.oneOnOneMeeting.findMany({
    where: {
      startsAt: { gte: new Date(`${from}T00:00:00`), lte: new Date(`${to}T23:59:59.999`) },
      status: { not: 'CANCELED' },
      series: { OR: [{ userAId: viewer.userId }, { userBId: viewer.userId }] },
    },
    include: SERIES_INCLUDE,
    orderBy: { startsAt: 'asc' },
  })
  const abertas = await db.oneOnOneAction.groupBy({
    by: ['seriesId'],
    where: { status: 'OPEN', seriesId: { in: meetings.map((m) => m.seriesId) } },
    _count: { _all: true },
  })
  const porSerie = new Map(abertas.map((linha) => [linha.seriesId, linha._count._all]))
  return meetings.map((meeting) =>
    toOneOnOneMeetingSummary(meeting, viewer.userId, porSerie.get(meeting.seriesId) ?? 0),
  )
}

export async function getMeeting(
  viewer: OneOnOneViewer,
  meetingId: string,
): Promise<OneOnOneMeetingDetailDTO> {
  const db = scopedPrisma(viewer.companyId)
  const meeting = await findParticipantMeeting(viewer, meetingId)

  const [topics, acoes, note] = await Promise.all([
    db.oneOnOneTopic.findMany({ where: { meetingId }, orderBy: { sortOrder: 'asc' } }),
    db.oneOnOneAction.findMany({
      // Ações do PAR (série), não só as deste encontro: é o que faz o combinado
      // sobreviver de um 1:1 para o outro.
      where: { seriesId: meeting.seriesId },
      include: { owner: true },
      orderBy: { createdAt: 'asc' },
    }),
    db.oneOnOnePrivateNote.findUnique({
      where: { meetingId_authorId: { meetingId, authorId: viewer.userId } },
    }),
  ])

  const abertas = acoes.filter((acao) => acao.status === 'OPEN')
  const fechadasAqui = acoes.filter((acao) => acao.status !== 'OPEN' && acao.createdInMeetingId === meetingId)

  return {
    ...toOneOnOneMeetingSummary(meeting, viewer.userId, abertas.length),
    topics: topics.map(toOneOnOneTopicDTO),
    openActions: abertas.map(toOneOnOneActionDTO),
    closedActions: fechadasAqui.map(toOneOnOneActionDTO),
    // A nota do outro participante não é buscada — não existe caminho para ela.
    note: note?.body ?? null,
    pdi: null,
  }
}

export { findParticipantMeeting }
```

```ts
import { ONE_ON_ONE_ACTION_DESCRIPTION_MAX_LENGTH, type OneOnOneActionDTO } from '@legends/shared'
import { notifyOneOnOneActionAssigned } from './notification-service'

async function findParticipantAction(viewer: OneOnOneViewer, actionId: string) {
  const action = await scopedPrisma(viewer.companyId).oneOnOneAction.findUnique({
    where: { id: actionId },
    include: { owner: true, series: true },
  })
  if (!action) throw new OneOnOneError('Ação não encontrada.', 404)
  if (viewer.userId !== action.series.userAId && viewer.userId !== action.series.userBId) {
    throw new OneOnOneError('Ação não encontrada.', 404)
  }
  return action
}

export async function createActionItem(
  viewer: OneOnOneViewer,
  meetingId: string,
  input: { description: string; ownerId: string; dueDate: string | null },
): Promise<OneOnOneActionDTO> {
  const meeting = await findParticipantMeeting(viewer, meetingId)
  const description = input.description.trim().slice(0, ONE_ON_ONE_ACTION_DESCRIPTION_MAX_LENGTH)
  if (!description) throw new OneOnOneError('Descreva a ação combinada.')
  // Dono precisa ser um dos dois: ação de 1:1 é combinado do par, não delegação.
  if (input.ownerId !== meeting.series.userAId && input.ownerId !== meeting.series.userBId) {
    throw new OneOnOneError('O responsável precisa ser uma das duas pessoas do 1:1.')
  }

  const action = await scopedPrisma(viewer.companyId).oneOnOneAction.create({
    data: {
      seriesId: meeting.seriesId,
      createdInMeetingId: meetingId,
      description,
      ownerId: input.ownerId,
      dueDate: input.dueDate ? new Date(input.dueDate) : null,
      companyId: viewer.companyId,
    },
    include: { owner: true },
  })

  if (input.ownerId !== viewer.userId) {
    const autor = meeting.series.userAId === viewer.userId ? meeting.series.userA : meeting.series.userB
    // Best-effort, no padrão do resto do repo: falhar ao notificar não desfaz o combinado.
    await notifyOneOnOneActionAssigned({
      userId: input.ownerId,
      actorId: viewer.userId,
      actorName: autor.name,
      meetingId,
      description,
      companyId: viewer.companyId,
    }).catch((err) => console.error('[one-on-one] falha ao notificar dono da ação', err))
  }
  return toOneOnOneActionDTO(action)
}

export async function updateActionItem(
  viewer: OneOnOneViewer,
  actionId: string,
  input: { description?: string; ownerId?: string; dueDate?: string | null; status?: 'OPEN' | 'DONE' },
): Promise<OneOnOneActionDTO> {
  const atual = await findParticipantAction(viewer, actionId)
  if (atual.status === 'PROMOTED') {
    throw new OneOnOneError('Esta ação virou ação de PDI — o acompanhamento é por lá.', 409)
  }

  const data: Record<string, unknown> = {}
  if (input.description !== undefined) {
    const description = input.description.trim().slice(0, ONE_ON_ONE_ACTION_DESCRIPTION_MAX_LENGTH)
    if (!description) throw new OneOnOneError('Descreva a ação combinada.')
    data.description = description
  }
  if (input.ownerId !== undefined) {
    if (input.ownerId !== atual.series.userAId && input.ownerId !== atual.series.userBId) {
      throw new OneOnOneError('O responsável precisa ser uma das duas pessoas do 1:1.')
    }
    data.ownerId = input.ownerId
  }
  if (input.dueDate !== undefined) data.dueDate = input.dueDate ? new Date(input.dueDate) : null
  if (input.status !== undefined) {
    data.status = input.status
    // Concluir grava quem fechou; reabrir limpa o rastro para não mentir depois.
    data.completedById = input.status === 'DONE' ? viewer.userId : null
    data.completedAt = input.status === 'DONE' ? new Date() : null
  }

  const action = await scopedPrisma(viewer.companyId).oneOnOneAction.update({
    where: { id: actionId },
    data,
    include: { owner: true },
  })
  return toOneOnOneActionDTO(action)
}
```

```ts
async function pdiBlockFor(
  viewer: OneOnOneViewer,
  series: { userAId: string; userBId: string; userA: { id: string; name: string; photoUrl: string | null; position: string | null }; userB: { id: string; name: string; photoUrl: string | null; position: string | null } },
): Promise<OneOnOnePdiBlockDTO | null> {
  const outroId = series.userAId === viewer.userId ? series.userBId : series.userAId
  const plan = await scopedPrisma(viewer.companyId).pdiPlan.findFirst({
    where: {
      status: { in: [...PLANOS_ATIVOS] },
      OR: [
        { userId: viewer.userId, leaderId: outroId },
        { userId: outroId, leaderId: viewer.userId },
      ],
    },
    include: { actions: { orderBy: { createdAt: 'asc' } } },
    orderBy: { updatedAt: 'desc' },
  })
  if (!plan) return null

  const dono = series.userA.id === plan.userId ? series.userA : series.userB
  return {
    planId: plan.id,
    planTitle: plan.title,
    owner: toOneOnOnePersonDTO(dono),
    actions: plan.actions.map((action) => ({
      id: action.id,
      description: action.description,
      status: action.status,
      progressPct: action.progressPct,
      dueDate: action.dueDate ? action.dueDate.toISOString() : null,
    })),
    canPromote: plan.userId === viewer.userId,
  }
}

/**
 * Promove o combinado do 1:1 a ação de PDI. Um dono só, um status só: a ação
 * daqui vira `PROMOTED` e sai dos pendentes, porque a cobrança passa a ser do
 * PDI — onde já existe validação do líder.
 */
export async function promoteActionToPdi(
  viewer: OneOnOneViewer,
  actionId: string,
): Promise<OneOnOneActionDTO> {
  const db = scopedPrisma(viewer.companyId)
  const acao = await findParticipantAction(viewer, actionId)
  if (acao.status === 'PROMOTED') throw new OneOnOneError('Esta ação já está no PDI.', 409)
  if (acao.status === 'DONE') throw new OneOnOneError('Esta ação já foi concluída.', 409)

  const plan = await db.pdiPlan.findFirst({
    where: { userId: viewer.userId, status: { in: [...PLANOS_ATIVOS] } },
    orderBy: { updatedAt: 'desc' },
  })
  if (!plan) {
    // O plano é da pessoa: o líder não escreve nele nem por aqui.
    const ehDoOutro = await db.pdiPlan.findFirst({
      where: { userId: { not: viewer.userId }, status: { in: [...PLANOS_ATIVOS] }, leaderId: viewer.userId },
      select: { id: true },
    })
    if (ehDoOutro) throw new OneOnOneError('Só a própria pessoa adiciona ações ao PDI dela.', 403)
    throw new OneOnOneError('Você ainda não tem um plano de PDI ativo.', 400)
  }

  const pdiAction = await db.pdiAction.create({
    data: {
      planId: plan.id,
      description: acao.description,
      type: 'OTHER',
      priority: 'MEDIUM',
      dueDate: acao.dueDate,
      companyId: viewer.companyId,
    },
  })
  await db.pdiActionHistory.create({
    data: {
      actionId: pdiAction.id,
      eventType: 'CREATED',
      actorId: viewer.userId,
      metadata: { origem: 'one-on-one', oneOnOneActionId: acao.id },
      companyId: viewer.companyId,
    },
  })

  const atualizada = await db.oneOnOneAction.update({
    where: { id: actionId },
    data: { status: 'PROMOTED', promotedPdiActionId: pdiAction.id },
    include: { owner: true },
  })
  return toOneOnOneActionDTO(atualizada)
}
```

```ts
export type OneOnOneScope = 'this' | 'future'

/**
 * Remarcar. `this` move uma ocorrência; `future` move esta e as seguintes pelo
 * MESMO deslocamento, preservando o intervalo entre elas — encontro passado
 * nunca é reescrito.
 */
export async function rescheduleMeeting(
  viewer: OneOnOneViewer,
  meetingId: string,
  input: { date: string; startTime: string; durationMinutes: number },
  scope: OneOnOneScope,
): Promise<OneOnOneMeetingSummaryDTO[]> {
  const db = scopedPrisma(viewer.companyId)
  const meeting = await findParticipantMeeting(viewer, meetingId)
  const novo = new Date(`${input.date}T${input.startTime}:00`)
  if (Number.isNaN(novo.getTime())) throw new OneOnOneError('Data ou hora inválida.')
  const deslocamento = novo.getTime() - meeting.startsAt.getTime()

  const alvos =
    scope === 'this'
      ? [meeting]
      : await db.oneOnOneMeeting.findMany({
          where: { seriesId: meeting.seriesId, startsAt: { gte: meeting.startsAt }, status: 'SCHEDULED' },
          include: SERIES_INCLUDE,
          orderBy: { startsAt: 'asc' },
        })

  const atualizados = await db.$transaction(
    alvos.map((alvo) => {
      const startsAt = new Date(alvo.startsAt.getTime() + deslocamento)
      return db.oneOnOneMeeting.update({
        where: { id: alvo.id },
        data: { startsAt, endsAt: new Date(startsAt.getTime() + input.durationMinutes * 60_000) },
        include: SERIES_INCLUDE,
      })
    }),
  )
  return atualizados.map((m) => toOneOnOneMeetingSummary(m, viewer.userId, 0))
}

export async function cancelMeeting(
  viewer: OneOnOneViewer,
  meetingId: string,
  scope: OneOnOneScope,
): Promise<void> {
  const db = scopedPrisma(viewer.companyId)
  const meeting = await findParticipantMeeting(viewer, meetingId)
  await db.oneOnOneMeeting.updateMany({
    where:
      scope === 'this'
        ? { id: meetingId }
        : { seriesId: meeting.seriesId, startsAt: { gte: meeting.startsAt }, status: 'SCHEDULED' },
    data: { status: 'CANCELED' },
  })
  if (scope === 'future') {
    await db.oneOnOneSeries.update({ where: { id: meeting.seriesId }, data: { endedAt: new Date() } })
  }
}

export async function markMeetingDone(
  viewer: OneOnOneViewer,
  meetingId: string,
): Promise<OneOnOneMeetingSummaryDTO> {
  await findParticipantMeeting(viewer, meetingId)
  const meeting = await scopedPrisma(viewer.companyId).oneOnOneMeeting.update({
    where: { id: meetingId },
    data: { status: 'DONE' },
    include: SERIES_INCLUDE,
  })
  return toOneOnOneMeetingSummary(meeting, viewer.userId, 0)
}
```

```ts
export async function oneOnOneRoutes(app: FastifyInstance) {
  const gate = { onRequest: [app.authenticate, app.requireFeature('um-a-um')] }

  function viewerOf(request: { user: { sub: string; companyId: string } }) {
    return { userId: request.user.sub, companyId: request.user.companyId }

    throw err

    if (!parsed.success) return badInput(reply, parsed.error)

      const criado = await createSeries(viewerOf(request), parsed.data)
      return reply.code(201).send(criado)
    } catch (err) {
      return handle(reply, err)
    }

    const params = idParams.safeParse(request.params)
    if (!params.success) return badInput(reply, params.error)

      return reply.send(await getMeeting(viewerOf(request), params.data.id))
    } catch (err) {
      return handle(reply, err)
    }

    const params = idParams.safeParse(request.params)
    if (!params.success) return badInput(reply, params.error)
```

```ts
import { Prisma } from '@prisma/client'
import type { OneOnOneTopicTemplateDTO } from '@legends/shared'
import { scopedPrisma } from '../lib/tenant-scope'
import { recordAuditLog } from './audit-log-service'

export interface TopicTemplateActor {
  id: string
  companyId: string
}

export class TopicTemplateError extends Error {
  status: number
  constructor(message: string, status = 400) {
    super(message)
    this.name = 'TopicTemplateError'
    this.status = status
  }
}

function toDTO(t: {
  id: string
  theme: string
  text: string
  active: boolean
  sortOrder: number
}): OneOnOneTopicTemplateDTO {
  return { id: t.id, theme: t.theme, text: t.text, active: t.active, sortOrder: t.sortOrder }
}

/** A tela do admin mostra inativo também — é ele que decide reativar. */
export async function listTopicTemplatesAdmin(actor: TopicTemplateActor): Promise<OneOnOneTopicTemplateDTO[]> {
  const templates = await scopedPrisma(actor.companyId).oneOnOneTopicTemplate.findMany({
    orderBy: [{ theme: 'asc' }, { sortOrder: 'asc' }],
  })
  return templates.map(toDTO)
}

export async function createTopicTemplate(
  actor: TopicTemplateActor,
  input: { theme: string; text: string; sortOrder?: number },
): Promise<OneOnOneTopicTemplateDTO> {
  const db = scopedPrisma(actor.companyId)
  return db.$transaction(async (tx) => {
    const created = await tx.oneOnOneTopicTemplate.create({
      data: {
        theme: input.theme.trim(),
        text: input.text.trim(),
        sortOrder: input.sortOrder ?? 0,
        companyId: actor.companyId,
      },
    })
    await recordAuditLog({
      actorId: actor.id,
      entityType: 'OneOnOneTopicTemplate',
      entityId: created.id,
      action: 'CREATE',
      after: created,
      companyId: actor.companyId,
      tx: tx as unknown as Prisma.TransactionClient,
    })
    return toDTO(created)
  })
}

export async function updateTopicTemplate(
  actor: TopicTemplateActor,
  id: string,
  input: { theme?: string; text?: string; active?: boolean; sortOrder?: number },
): Promise<OneOnOneTopicTemplateDTO> {
  const db = scopedPrisma(actor.companyId)
  const before = await db.oneOnOneTopicTemplate.findUnique({ where: { id } })
  if (!before) throw new TopicTemplateError('Tópico não encontrado.', 404)

  return db.$transaction(async (tx) => {
    const updated = await tx.oneOnOneTopicTemplate.update({
      where: { id },
      data: {
        theme: input.theme?.trim(),
        text: input.text?.trim(),
        active: input.active,
        sortOrder: input.sortOrder,
      },
    })
    await recordAuditLog({
      actorId: actor.id,
      entityType: 'OneOnOneTopicTemplate',
      entityId: id,
      action: 'UPDATE',
      before,
      after: updated,
      companyId: actor.companyId,
      tx: tx as unknown as Prisma.TransactionClient,
    })
    return toDTO(updated)
  })
}

export async function deleteTopicTemplate(actor: TopicTemplateActor, id: string): Promise<void> {
  const db = scopedPrisma(actor.companyId)
  const before = await db.oneOnOneTopicTemplate.findUnique({ where: { id } })
  if (!before) throw new TopicTemplateError('Tópico não encontrado.', 404)

  await db.$transaction(async (tx) => {
    await tx.oneOnOneTopicTemplate.delete({ where: { id } })
    await recordAuditLog({
      actorId: actor.id,
      entityType: 'OneOnOneTopicTemplate',
      entityId: id,
      action: 'DELETE',
      before,
      companyId: actor.companyId,
      tx: tx as unknown as Prisma.TransactionClient,
    })
  })
}
```

```tsx
import { NewOneOnOneModal } from './NewOneOnOneModal'

/** Janela da lista: do mês passado a três meses à frente. */
function janela(): { from: string; to: string } {
  const hoje = new Date()
  const from = new Date(hoje.getFullYear(), hoje.getMonth() - 1, 1)
  const to = new Date(hoje.getFullYear(), hoje.getMonth() + 3, 0)
  const iso = (d: Date) => d.toISOString().slice(0, 10)
  return { from: iso(from), to: iso(to) }
}

function quando(startsAt: string): string {
  return new Intl.DateTimeFormat('pt-BR', {
    weekday: 'short',
    day: '2-digit',
    month: 'short',
    hour: '2-digit',
    minute: '2-digit',
  }).format(new Date(startsAt))
}

function MeetingCard({ meeting }: { meeting: OneOnOneMeetingSummaryDTO }) {
  return (
    <Link
      to={`/1-1/${meeting.id}`}
      className="flex items-center justify-between rounded-lg border border-slate-200 bg-white p-4 hover:border-slate-300"
    >
      <div>
        <p className="font-medium text-slate-900">{meeting.counterpart.name}</p>
        <p className="text-sm text-slate-500">{quando(meeting.startsAt)}</p>
      </div>
      {meeting.openActionCount > 0 && (
        <span className="rounded-full bg-amber-100 px-3 py-1 text-xs font-medium text-amber-800">
          {meeting.openActionCount} {meeting.openActionCount === 1 ? 'ação em aberto' : 'ações em aberto'}
        </span>
      )}
    </Link>
  )
}

export function OneOnOnePage() {
  const [novoAberto, setNovoAberto] = useState(false)
  const { from, to } = useMemo(janela, [])
  const { data, isLoading } = useQuery({
    queryKey: ['one-on-ones', from, to],
    queryFn: () => listOneOnOnes(from, to),
  })

  const agora = Date.now()
  const meetings = data?.meetings ?? []
  const proximos = meetings.filter((m) => new Date(m.startsAt).getTime() >= agora)
  const passados = meetings.filter((m) => new Date(m.startsAt).getTime() < agora).reverse()

  return (
    <div className="mx-auto max-w-3xl space-y-8 p-6">
      <header className="flex items-center justify-between">
        <div>
          <h1 className="text-2xl font-semibold text-slate-900">1:1</h1>
          <p className="text-sm text-slate-500">Suas conversas, a pauta e o que ficou combinado.</p>
        </div>
        <button
          type="button"
          onClick={() => setNovoAberto(true)}
          className="rounded-lg bg-slate-900 px-4 py-2 text-sm font-medium text-white"
        >
          Marcar 1:1
        </button>
      </header>

      {isLoading && <p className="text-sm text-slate-500">Carregando…</p>}

      {!isLoading && meetings.length === 0 && (
        <p className="rounded-lg border border-dashed border-slate-300 p-8 text-center text-sm text-slate-500">
          Você ainda não tem nenhum 1:1 marcado.
        </p>
      )}

      {proximos.length > 0 && (
        <section className="space-y-3">
          <h2 className="text-sm font-semibold uppercase tracking-wide text-slate-500">Próximos</h2>
          {proximos.map((meeting) => (
            <MeetingCard key={meeting.id} meeting={meeting} />
          ))}
        </section>
      )}

      {passados.length > 0 && (
        <section className="space-y-3">
          <h2 className="text-sm font-semibold uppercase tracking-wide text-slate-500">Anteriores</h2>
          {passados.map((meeting) => (
            <MeetingCard key={meeting.id} meeting={meeting} />
          ))}
        </section>
      )}

      {novoAberto && <NewOneOnOneModal onClose={() => setNovoAberto(false)} />}
    </div>
  )
}
```

```tsx
}
```

```tsx
  const [counterpartId, setCounterpartId] = useState('')
  const [date, setDate] = useState('')
  const [startTime, setStartTime] = useState('')
  const [durationMinutes, setDuration] = useState(30)
  const [recurrence, setRecurrence] = useState<OneOnOneRecurrence>('NONE')
  const [recurrenceCount, setCount] = useState(8)
  const [erro, setErro] = useState<string | null>(null)

  const marcar = useMutation({
    mutationFn: () =>
      createOneOnOne({
        counterpartId,
        date,
        startTime,
        durationMinutes,
        recurrence,
        // Só um dos dois fins viaja: a API recusa os dois juntos.
        recurrenceCount: recurrence === 'NONE' ? null : recurrenceCount,
      }),
    onSuccess: (resposta) => {
      queryClient.invalidateQueries({ queryKey: ['one-on-ones'] })
      onClose()
      if (resposta.meetings[0]) navigate(`/1-1/${resposta.meetings[0].id}`)
    },
    onError: (err: Error) => setErro(err.message),
  })

  return (
    <div className="fixed inset-0 z-40 flex items-center justify-center bg-slate-900/40 p-4">
      <form
        onSubmit={(event) => {
          event.preventDefault()
          setErro(null)
          marcar.mutate()
        }}
        className="w-full max-w-md space-y-4 rounded-lg bg-white p-6"
      >
        <h2 className="text-lg font-semibold text-slate-900">Marcar 1:1</h2>

        <label className="block text-sm">
          Com quem
          <select
            value={counterpartId}
            onChange={(event) => setCounterpartId(event.target.value)}
            required
            className="mt-1 w-full rounded border border-slate-300 px-3 py-2"
          >
            <option value="">Escolha uma pessoa</option>
            {(colegas ?? []).map((colega) => (
              <option key={colega.id} value={colega.id}>
                {colega.name}
              </option>
            ))}
          </select>
        </label>

        <div className="grid grid-cols-2 gap-3">
          <label className="block text-sm">
            Data
            <input
              type="date"
              value={date}
              onChange={(event) => setDate(event.target.value)}
              required
              className="mt-1 w-full rounded border border-slate-300 px-3 py-2"
            />
          </label>
          <label className="block text-sm">
            Horário
            <input
              type="time"
              value={startTime}
              onChange={(event) => setStartTime(event.target.value)}
              required
              className="mt-1 w-full rounded border border-slate-300 px-3 py-2"
            />
          </label>
        </div>

        <label className="block text-sm">
          Duração
          <select
            value={durationMinutes}
            onChange={(event) => setDuration(Number(event.target.value))}
            className="mt-1 w-full rounded border border-slate-300 px-3 py-2"
          >
            {ONE_ON_ONE_DURATIONS_MINUTES.map((minutos) => (
              <option key={minutos} value={minutos}>
                {minutos} minutos
              </option>
            ))}
          </select>
        </label>

        <label className="block text-sm">
          Ritmo
          <select
            value={recurrence}
            onChange={(event) => setRecurrence(event.target.value as OneOnOneRecurrence)}
            className="mt-1 w-full rounded border border-slate-300 px-3 py-2"
          >
            {ONE_ON_ONE_RECURRENCES.map((valor) => (
              <option key={valor} value={valor}>
                {ONE_ON_ONE_RECURRENCE_LABELS[valor]}
              </option>
            ))}
          </select>
        </label>

        {recurrence !== 'NONE' && (
          <label className="block text-sm">
            Quantos encontros
            <input
              type="number"
              min={1}
              max={52}
              value={recurrenceCount}
              onChange={(event) => setCount(Number(event.target.value))}
              className="mt-1 w-full rounded border border-slate-300 px-3 py-2"
            />
          </label>
        )}

        {erro && <p className="text-sm text-rose-600">{erro}</p>}

        <div className="flex justify-end gap-2">
          <button type="button" onClick={onClose} className="rounded px-4 py-2 text-sm text-slate-600">
            Cancelar
          </button>
          <button
            type="submit"
            disabled={marcar.isPending}
            className="rounded bg-slate-900 px-4 py-2 text-sm text-white disabled:opacity-60"
          >
            Marcar
          </button>
        </div>
      </form>
    </div>
  )
}
```
