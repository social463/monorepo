# Cultura (Manifesto, Manuais, Benefícios) — Implementation Plan

**Goal:** Entregar a área **Cultura** do Legends — Manifesto cultural, Manuais internos e
Benefícios — com todo o conteúdo vindo do banco e editável pela área administrativa, atrás da
feature `cultura`. Fecha o PBI 22226 (tasks 22227, 22228, 22229) num PR só.

**Architecture:** Padrão do repo — contrato em `@legends/shared` → models Prisma tenant-scoped →
`services/culture-service.ts` (regra + erro tipado) → `routes/culture.ts` (fina, Zod, serialize) →
React Query + páginas. Conteúdo institucional em **Markdown**, renderizado por componente próprio
que emite elementos React (sem dependência nova, sem `dangerouslySetInnerHTML`). PDF de manual vai
para o S3 por presign e é baixado por rota autenticada.

**Tech Stack:** Fastify 4, Prisma 5 + PostgreSQL, Zod, Vitest (+ Postgres real), React 18 + React
Query + React Router 6, Tailwind 3, TypeScript ESM.

Spec: `docs/superpowers/specs/2026-07-30-cultura-design.md`.

## Global Constraints

- **Nada de conteúdo hardcoded** na área de Cultura — tudo sai do banco e é editável no admin.
- Manifesto e Benefícios: `requireAdmin`. Manuais: `requireAdminOrSubadmin`. Validação sempre no
  backend; a web só esconde a UI.
- Leitura pelo colaborador devolve **apenas `published`**; rascunho só pela rota de admin.
- Todo model novo entra em `TENANT_SCOPED_MODELS` (`lib/tenant-scope.ts`) — a lista é manual e é o
  que garante o isolamento por empresa — e no truncate de `test/setup.ts`.
- `fileKey` no banco, **nunca** URL pública de S3; download só por
  `GET /culture/manuals/:id/download` (sessão + feature → presign de 5 min).
- Erros de domínio via `CultureError` com `status`; a route faz `instanceof`.
- Sem S3 configurado: presign responde `503` e a UI esconde o campo de arquivo.
- Mensagens ao usuário em **português**. Nunca editar migration já aplicada.
